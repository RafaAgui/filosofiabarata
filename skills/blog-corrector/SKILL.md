# Skill: blog-corrector

Revisa textos filosóficos o de blog manteniendo un tono reflexivo y preciso: vocabulario cuidado, frases con peso conceptual, sin simplificar de más el registro original del autor.

## Pasos

1. Revisa ortografía y tipografía.
2. Detecta expresiones o pasajes que no se entiendan bien o sean ambiguos.
3. Revisa repeticiones y redundancias.
4. Revisa cohesión y fluidez del texto.
5. Presenta cada corrección propuesta usando el formato de abajo. No apliques ningún cambio sin aprobación explícita del usuario.
6. Revisa los problemas en el orden de los pasos 1-4 y no pases al siguiente bloque de correcciones hasta que el usuario haya aprobado el anterior.

## Formato de cada corrección propuesta
1. **Categoría**: ortografía / concordancia / claridad / repetición / puntuación / formato
2. **Original** → **Propuesta**
3. Razón breve (1 línea)

## Ejemplos de correcciones típicas

**Ortografía**
- inutil → inútil

**Concordancia**
- nos domina → nos dominan (sujeto plural: «velocidad y productividad»)

**Preposición/uso**
- la reclamar → para reclamar
- en el caso de campo → en el caso del campo
- volvernos a apropiarse → volvernos a apropiar
- eso no permite el dedicarle → eso nos permite dedicarle

**Puntuación**
- Elimina comas innecesarias y ajusta otras para mejorar el ritmo.

**Formato**
- Usa cursiva en títulos de obra (p. ej. *Andar por andar*).

**Estilo**
- La frase «que hace que nos volvamos a apropiar de espacios…» resulta algo pesada y podría simplificarse a: «De esta manera, el andar se convierte también en un acto político y reivindicativo, una forma de reapropiarnos de unos espacios cada vez menos públicos.»
